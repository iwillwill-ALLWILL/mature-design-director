# Creative Foundation and Mechanics Ledger

> Private production record. Separate what authors the experience from what assembles it.

## Creative foundation

| Visible / audible layer | Adopted source or system | Provenance / license | Mature benchmark role | Representative proof and selection evidence |
|---|---|---|---|---|
|  |  |  |  |  |

Valid foundations include an approved product or brand system, approved artboards or look frames, a real editorial/game/spatial/sonic system, real or licensed media, production assets, and authored source material.

`custom`, `generated`, `CSS`, `PptxGenJS`, `HTML`, `engine`, or a tool name is not a completed foundation record. Custom or generated visual language must name the adoption gap, selected references, final-scale proof, comparative review, and selection authority.

## Assembly mechanics

| Production job | Adopted tool / runtime | Version / license | Executed spike or command | Exact output owned by this mechanic |
|---|---|---|---|---|
|  |  |  |  |  |

Mechanics may implement layout, interaction, rendering, encoding, file structure, engine integration, export, or packaging. They do not gain art-direction authority because the output opens, builds, or passes technical checks.
